# Contributing

Use Node.js 22 and npm 10+. Create a topic branch, run `npm ci`, `npm run typecheck`, and `npm test`. Add tests for state transitions, money calculations, authorization and concurrency. Do not commit `.env`, tokens, or personal location data. Open a pull request with a description, test evidence, and migration notes. Follow conventional commits (`feat:`, `fix:`, `docs:`, `test:`). External contributions are reviewed before merging.
